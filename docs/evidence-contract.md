# Evidence contract

The active Free chain is:

summary observation → Element → Pattern or Hero Portfolio insight → story

Every public Element carries a stable key, label, status, score or explicit
absence, confidence, sample size, coverage, axis, zone, receipts, confounders,
missing-data reasons, and methodology version. Raw scorer metrics and source
match IDs are private.

A Pattern names required Element keys separately from modifier Element keys.
Only required Elements gate qualification. The public result carries status,
direction, strength, relationship strength, confidence, coverage, family,
tier, and public receipts.

Hero Portfolio has independent eligibility and margin gates for Common Thread,
Exception, Pool Evolution, and Hero Mirror. No-clear and unavailable are valid
outputs; they are not replaced with neutral guesses.

Free enforces detail_requests = 0 and parse_requests = 0. Public output contains
no raw match IDs, raw scorer metrics, account IDs, or private payload refs.
