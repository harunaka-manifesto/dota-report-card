Each definition lists required_elements and modifier_elements separately.
Required Elements gate qualification. Modifiers add context and evidence but
never silently become gates. Results expose both references, status, direction,
strength, confidence, coverage, family, tier, receipts, confounders, and
suppression reasons.

Qualification is deterministic, description-first, and fail-closed. The web
story leads with the human Pattern explanation and exposes Element ingredients
only on expansion.
